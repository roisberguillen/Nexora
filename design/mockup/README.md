# Mockup ufficiale Nexora

Questa directory contiene il mockup fornito dal product owner e integrato nel repository come riferimento UX/UI ufficiale.

## Contenuto

- `stitch/screen.png` — schermata di riferimento.
- `stitch/code.html` — prototipo esplorabile.
- `stitch/DESIGN.md` — design system e token originali.

Prima di implementare l'interfaccia leggere `docs/ux/MOCKUP_INTEGRATION.md`.

I file originali devono essere conservati senza modifiche. Eventuali implementazioni derivate vanno create nei package e nelle app del monorepo, non in questa directory.
