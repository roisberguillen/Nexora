# Skill: Nexora Domain
Usare per modifiche a conti, transazioni, trasferimenti, budget, ricorrenze, prestiti o investimenti.

Checklist:
1. Identificare invarianti coinvolti.
2. Scrivere test di dominio prima o insieme al codice.
3. Usare Money in minor units.
4. Verificare impatto su saldo, patrimonio, income/expense report.
5. Aggiornare schema e ADR se cambia una decisione strutturale.
